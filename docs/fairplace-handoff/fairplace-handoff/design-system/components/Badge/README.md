Etiqueta pequena de status ou categoria, mais o eyebrow e a caixa de ícone que carregam a identidade das categorias.

- `fp-badge--verified`: vendedor verificado, sempre com o ícone de check e a palavra "Verificado".
- `fp-badge--feira`, `--artesanato`, `--agricultura`: categoria, com o nome por extenso.
- `fp-badge--off`: produto indisponível.
- `fp-eyebrow`: rótulo em caixa alta acima de um título de seção, com a bolinha `yellow`.
- `fp-iconbox`: ícone de linha em caixa de 40px (`--lg` para 64px), no tom `-soft` da categoria.

Você fornece o texto e a variante. Badge não é clicável; para filtrar use FilterChip. No máximo dois badges por card (categoria e Verificado).
