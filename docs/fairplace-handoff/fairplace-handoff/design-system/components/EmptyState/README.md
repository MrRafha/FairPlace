Bloco de estado vazio, sem resultado ou erro leve, com borda tracejada.

Caixa de ícone grande, título curto em `h3`, uma frase em `muted` e, quando existe algo a fazer, um único botão. Usos previstos: vitrine sem produtos, "Nenhuma publicação ainda", busca ou filtro sem resultado, localização negada, favoritos vazios.

Você fornece ícone, título, frase e a ação (opcional). O tom convida, nunca culpa. Ocupa o lugar exato do conteúdo que falta (dentro da seção ou da barra lateral), não a tela toda. Para carregamento, não use EmptyState: use os blocos `fp-skel` no formato do conteúdo que vai chegar.
